## Changes made in this package

The original workbook is preserved. Source CSVs extract worksheet values. Processed CSVs
rename fields and correct two product-group labels. Configuration IDs, order mappings,
grouped demand, physical/identity BOM splits, gross component requirements and initial
arrival periods are new derived data. The pipeline, project policies and recommendations
are an independent learning implementation and do not imply author or company endorsement.
Source hashes and extraction details are in data/source_manifest.json.
